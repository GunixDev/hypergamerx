## ¿Qué pico necesito para conseguir Ámbar?
En lego Fortnite existen varios tipos de picos, esto mas que todo varían por la calidad de estos mismos, los cuales con algunos picos puedes picar ciertos cosas como por ejemplo con un pico de rareza ("raro"), se puede picar <Ref url="guias/how-to-get-obsidian-in-fortnite-lego" text="obsidiana"/> y <Ref url="guias/how-to-get-copper-in-lego-fortnite" text="cobre"/>, igualmente funciona con otros pico.

En nuestro caso para poder picar el material de ámbar, necesitas primero un pico poco común, con esto podrás picar el ámbar de la manera mas fácil y lenta, si quieres mejorar como se pica mas rápido el ámbar, podrías conseguir un pico raro a mas rareza del pico, mucho mejor, pero para comenzar a conseguir el ámbar, se usa el pico poco común. Para poder craftear el pico común se necesita, 3 Vara de nudorraiz y 3 huesos, esto lo colocas en el banco de fabricación de nivel 2.
## ¿En que lugar consigo Ámbar?
En Lego Fortnite solamente existe un lugar en donde conseguir este material, que es el bioma del Valle Seco, en donde se podrá encontrar diferentes criaturas las cuales te pueden llevar a matar y también encontraras el famoso ámbar, el cual se encuentra en las mesetas de estas mismas. Estos minerales son de color amarilloso y se encuentra en la parte media alta de las mesetas, puedes usar escaleras para poder subir y sentirte cómodo al picar el ámbar y también puede usar los Geyser (huecos de agua que te elevan al cielo), para poder conseguir este mineral de ámbar, pero no es muy recomendado.
